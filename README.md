## Complete Roblox Game Development Course in Thai

---

**ผู้เรียน:** ทุกระดับ ตั้งแต่ผู้เริ่มต้นจนถึงระดับมืออาชีพ

## 📚 เกี่ยวกับคอร์สนี้

คอร์สนี้ออกแบบมาเพื่อสอนการพัฒนาเกม Roblox อย่างครบถ้วนตั้งแต่เริ่มต้น ไม่ว่าคุณจะเป็นผู้เริ่มต้นที่ไม่เคยเขียนโค้ดมาก่อน หรือนักพัฒนาที่มีประสบการณ์แล้วต้องการพัฒนาทักษะ คอร์สนี้มีเนื้อหาที่เหมาะสมสำหรับคุณ

### สิ่งที่คุณจะได้เรียนรู้:
- การใช้งาน Roblox Studio อย่างมืออาชีพ
- การเขียนภาษา Lua สำหรับ Roblox
- การสร้างเกมแนวต่างๆ (Action, RPG, Simulator, Obby)
- การทำ UI/UX ที่สวยงามและใช้งานได้จริง
- ระบบ Multiplayer และ Server-Client Architecture
- การใช้ DataStore สำหรับบันทึกข้อมูลผู้เล่น
- การทำรายได้จากเกม Roblox (Monetization)
- การ Publish และ Market เกมของคุณ

## 🗺️ แผนการเรียน (Learning Path)

### สัปดาห์ที่ 1-2: เริ่มต้น (ตอนที่ 1-10)
```
วันที่ 1: ตอนที่ 001-002 (แนะนำ + ติดตั้ง)
วันที่ 2: ตอนที่ 003-004 (Interface + Parts)
วันที่ 3: ตอนที่ 005-006 (Properties + Explorer)
วันที่ 4: ตอนที่ 007-008 (Baseplate + Terrain)
วันที่ 5: ตอนที่ 009-010 (Lua Basics + Variables)
สุดสัปดาห์: ทบทวนและทำแบบฝึกหัด
```

### สัปดาห์ที่ 3-5: Lua Programming (ตอนที่ 11-20)
```
ทบทวน Operators, Control Flow, Loops
เรียน Functions, Tables, Scripts
สร้างเกมง่ายๆ แรกของคุณ
```

### เดือนที่ 2: Intermediate (ตอนที่ 21-50)
```
เรียน OOP, Modules, Remote Events
สร้างระบบ UI, DataStore
พัฒนาเกมที่ซับซ้อนมากขึ้น
```

### เดือนที่ 3-4: Advanced (ตอนที่ 51-80)
```
เรียน Advanced Lua Patterns
สร้าง Game Systems ต่างๆ
เรียน Performance Optimization
```

### เดือนที่ 5-6: Professional (ตอนที่ 81-100)
```
Game Architecture Design
Monetization Strategies
Publishing and Marketing
Build Your Portfolio
```

## 🛠️ สิ่งที่ต้องเตรียม (Prerequisites)

### Hardware:
- คอมพิวเตอร์ที่รัน Windows 10/11 หรือ macOS 10.13+
- RAM อย่างน้อย 4GB (แนะนำ 8GB+)
- พื้นที่ว่างในดิสก์อย่างน้อย 2GB

### Software:
- **Roblox Studio** (ฟรี - ดาวน์โหลดจาก roblox.com)
- **บัญชี Roblox** (ฟรี)
- Text Editor เสริม: VS Code (แนะนำ)

### ความรู้เบื้องต้น:
- ไม่จำเป็นต้องมีประสบการณ์การเขียนโค้ดมาก่อน
- ความสามารถในการใช้คอมพิวเตอร์ขั้นพื้นฐาน

---

## 📖 วิธีใช้คอร์สนี้

1. **อ่านตามลำดับ** - เนื้อหาถูกออกแบบให้เรียนตามลำดับ
2. **ทำแบบฝึกหัด** - ทุกตอนมีแบบฝึกหัด ควรทำทุกข้อ
3. **ทดลองโค้ด** - Copy โค้ดตัวอย่างและลองรันใน Studio
4. **สร้าง Project** - สร้างโปรเจกต์จริงควบคู่ไปกับการเรียน
5. **ถามคำถาม** - อย่ากลัวที่จะทดลองและผิดพลาด
