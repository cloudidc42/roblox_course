# Part 99: Building a Portfolio and Career in Roblox Development

## บทนำ (Introduction)

Roblox ไม่ได้เป็นแค่แพลตฟอร์มเกม — มันเป็นแพลตฟอร์มสำหรับ developer มืออาชีพ
ในปี 2024 developer คนหนึ่งสามารถทำเงินได้หลักล้านบาทต่อปีจากเกมบน Roblox
บทนี้จะสอนวิธีสร้าง portfolio, หางาน, และสร้างอาชีพในวงการ Roblox

### สิ่งที่จะได้เรียนรู้:
- การสร้าง Portfolio ที่ดึงดูดนักจ้างงาน
- แพลตฟอร์มสำหรับหางาน Roblox
- วิธีราคาตัวเองและเจรจาต่อรอง
- การสร้างชื่อเสียงในชุมชน
- สร้าง Studio ของตัวเอง
- ทำงานใน studio ใหญ่ๆ
- อาชีพที่เกี่ยวข้องกับ Roblox

## ส่วนที่ 1: ทำความเข้าใจตลาดงาน Roblox

### 1.1 ประเภทงานใน Roblox

```
อาชีพหลักใน Roblox:

🎮 GAME DEVELOPER (Lua/Scripting)
   ระดับ: Junior → Mid → Senior → Lead
   เงินเดือน: $30,000 → $80,000+ ต่อปี (USD)
   (ไทย: 50,000 → 150,000+ บาท/เดือน)
   
   ทักษะที่ต้องการ:
   - Lua programming (พื้นฐาน-ขั้นสูง)
   - Roblox APIs (Services, Instances)
   - OOP และ design patterns
   - Git/Version control
   - Performance optimization
   - Networking (Remote Events/Functions)

🎨 BUILDER / 3D ARTIST
   ระดับ: Builder → Level Designer → Art Lead
   เงินเดือน: $25,000 → $70,000+ ต่อปี
   
   ทักษะที่ต้องการ:
   - Roblox Studio building
   - Blender 3D modeling
   - UV unwrapping และ texturing
   - Game feel และ level design
   - Lighting (Sky, Atmosphere, Surface Appearance)

🖥️ UI/UX DESIGNER
   ระดับ: UI Designer → UX Lead
   เงินเดือน: $30,000 → $75,000+ ต่อปี
   
   ทักษะที่ต้องการ:
   - Figma/Adobe XD สำหรับ mockups
   - Roblox UI scripting
   - Animation (Tween)
   - UX principles สำหรับเกม
   - Mobile-first design

🎵 SOUND DESIGNER
   ระดับ: Sound Designer
   เงินเดือน: $25,000 → $60,000+ ต่อปี
   
   ทักษะที่ต้องการ:
   - Audio production (DAW: FL Studio, Audacity)
   - Sound effects creation
   - Music composition
   - Roblox audio implementation

📊 GAME DESIGNER
   ระดับ: Designer → Lead Designer
   เงินเดือน: $35,000 → $85,000+ ต่อปี
   
   ทักษะที่ต้องการ:
   - Game balance และ economy design
   - Player psychology
   - Monetization strategy
   - Analytics interpretation
   - GDD (Game Design Document) writing

👔 PRODUCER / PROJECT MANAGER
   ระดับ: Producer → Executive Producer
   เงินเดือน: $45,000 → $100,000+ ต่อปี
   
   ทักษะที่ต้องการ:
   - Project management (Agile/Scrum)
   - Team leadership
   - Budget management
   - Publisher relations
   - Community management
```

## ส่วนที่ 2: สร้าง Portfolio ที่โดดเด่น

### 2.1 โครงสร้าง Portfolio

```
Portfolio Structure ที่ดี:

1. ABOUT ME (แนะนำตัว)
   - ชื่อ (หรือ username)
   - ตำแหน่งที่ต้องการ
   - ประสบการณ์ (กี่ปี)
   - ทักษะหลัก
   - ความเชี่ยวชาญ
   
   ตัวอย่าง:
   "Lua Developer with 3+ years experience building scalable
   game systems. Specialized in DataStore, combat systems,
   and performance optimization. Previously worked on games
   with 10M+ visits."

2. SHOWCASE PROJECTS (ผลงานหลัก 3-5 ชิ้น)
   แต่ละ project ควรมี:
   - ชื่อ game และลิงก์
   - Visit count (ถ้ามี)
   - หน้าที่ที่รับผิดชอบ
   - ทักษะที่ใช้
   - ภาพ screenshot หรือ video
   - ความท้าทายที่แก้ไขได้
   
3. SKILLS (ทักษะ)
   จัดกลุ่มตาม:
   - Programming: Lua, ModuleScripts, OOP
   - APIs: DataStore, Remotes, Services
   - Tools: Studio, Git, Rojo, VS Code
   - Soft skills: Communication, Teamwork
   
4. WORK EXPERIENCE (ประสบการณ์)
   - Studio name
   - ระยะเวลา
   - Role
   - Achievements (visit count, revenue)
   
5. TESTIMONIALS (คำรับรอง)
   - Quote จาก client หรือ team member
   - ชื่อและ role ของผู้พูด
   
6. CONTACT (ติดต่อ)
   - Discord username
   - Roblox profile
   - Email (ถ้าต้องการ)
   - Twitter/X (ถ้ามี)
```

## ส่วนที่ 3: หาและรับงาน

### 3.1 แพลตฟอร์มหางาน

```
แพลตฟอร์มหลักสำหรับหางาน Roblox:

1. ROBLOX TALENT HUB (talent.roblox.com)
   - แพลตฟอร์มหลักของ Roblox สำหรับ freelance
   - Post service listing ของตัวเอง
   - ค้นหา job postings
   - ชำระด้วย Robux
   - ฟรีในการสร้าง profile
   
   เทคนิค:
   - เขียน portfolio link ให้ชัดเจน
   - กำหนด rate ที่แม่นยำ
   - ตอบกลับเร็ว (ภายใน 24 ชั่วโมง)

2. DISCORD SERVERS
   Servers ที่แนะนำ:
   - Roblox Scripters: discord.gg/robloxscripting (ใหญ่มาก)
   - Roblox Studio Community
   - #hirings channels ในทุก Roblox community server
   
   วิธีใช้:
   - ดู #portfolio channel แล้ว post งานของตัวเอง
   - ดู #hirings/#commissions channel
   - อย่า DM คนโดยไม่ได้รับอนุญาต (spam)

3. TWITTER/X
   - Tag: #RobloxDev, #RobloxScripting
   - Follow studio owners และ developers
   - Share work progress (WIP posts)
   - คน hire ดู tweet เยอะมาก

4. REDDIT
   - r/RobloxDev - community discussions
   - r/roblox - general Roblox
   
5. LINKEDIN
   - สำหรับ full-time positions
   - Roblox Inc. และ indie studios post ที่นี่
   - Professional network

6. ROBLOX FORUMS (devforum.roblox.com)
   - #recruitment section
   - มี portfolio reviews
   - Community feedback
```

### 3.3 การกำหนดราคา (Pricing)

```
วิธีกำหนดราคาสำหรับงาน Roblox:

ROBUX RATES (ปี 2024):
   Junior Developer: 3,000-8,000 R$ ต่อชั่วโมง
   Mid Developer: 8,000-20,000 R$ ต่อชั่วโมง
   Senior Developer: 20,000-50,000+ R$ ต่อชั่วโมง
   
   ราคาต่อชิ้นงาน (Fixed price):
   Basic system: 5,000-20,000 R$
   Complex system: 20,000-100,000 R$
   Full game: 100,000-500,000+ R$

USD RATES:
   Junior: $15-30/hr
   Mid: $30-60/hr
   Senior: $60-150+/hr

ปัจจัยที่ส่งผลต่อราคา:
   + มีประสบการณ์มาก
   + ผลงานที่ successful (visit count สูง)
   + ทักษะเฉพาะทาง (anti-cheat, optimization)
   + ชื่อเสียงดีในชุมชน
   + Deadline เร่งด่วน (rush fee 20-50%)
   
   - ยังใหม่ ไม่มี portfolio
   - Project ไม่ชัดเจน (scope creep risk)
   - Client ไม่มีชื่อเสียง

Robux ต่อ USD Exchange:
   Roblox DevEx rate: ~0.0035 USD per Robux
   (1000 R$ = $3.50 USD)
   
   แต่ต้องมีขั้นต่ำ 50,000 R$ และเป็น Premium member
   ก่อน DevEx ได้

TIP: ถ้าเป็นงานใหม่หรือ portfolio piece ให้ทำฟรีหรือราคาต่ำพิเศษ
     เพื่อแลกกับ testimonial และ credit ในเกม
```

## ส่วนที่ 5: สร้าง Studio ของตัวเอง

### 5.1 จาก Solo ไปสู่ Studio

```
ขั้นตอนการสร้าง Studio:

Stage 1: Solo Developer (0-6 เดือน)
   - พัฒนาเกมแรกคนเดียว
   - เรียนรู้ทุกด้าน (scripting, building, UI)
   - สร้าง first hit game
   - เก็บ revenue เป็น operating capital

Stage 2: First Hire (6-12 เดือน)
   - ตัดสินใจว่าต้องการ talent ด้านไหน
   - เริ่มจาก 1 คน (คนที่ complement ทักษะของเรา)
   - สร้าง workflow ร่วมกัน
   - กำหนด rev share ที่ยุติธรรม

Stage 3: Small Team (1-2 ปี)
   - ทีม 3-5 คน
   - แต่ละคนมี role ชัดเจน
   - เริ่มมี HR process
   - พัฒนาหลาย project พร้อมกัน

Stage 4: Established Studio (2+ ปี)
   - ทีม 10+ คน
   - มี office หรือ virtual office
   - รับ investment หรือ publisher deal
   - มี multiple hits

Business Structure:
   - เริ่มต้น: revenue split agreement (ไม่ต้องจดบริษัท)
   - ต่อมา: LLC หรือ บริษัทจำกัด
   - ใหญ่ขึ้น: Series A funding, publisher deals

Thai Studio Considerations:
   - จดทะเบียนบริษัทในไทย (หรือ US LLC สำหรับ international)
   - ภาษี: รายได้จาก Roblox ต้องเสียภาษี
   - ธนาคาร: ต้องมี account ที่รับ USD/international transfer
   - DevEx: Roblox ต้องยืนยัน tax information (W-9/W-8BEN)
```

### 5.2 Revenue & Business Model

```
Business Models สำหรับ Roblox Studio:

1. GAME REVENUE (รายได้หลัก)
   - Developer Products: ซื้อของในเกม
   - GamePasses: ซื้อครั้งเดียว
   - Premium Payouts: จาก Premium members
   - Subscriptions: รายเดือน
   
   Formula: Revenue = DAU × ARPU
   (Daily Active Users × Average Revenue Per User)
   
   Target ARPU ที่ดี: $0.05-0.50 per DAU per day

2. FREELANCE WORK
   - รับงานจาก clients
   - ทำงาน commission
   - ทำให้ revenue มี baseline

3. ASSET MARKETPLACE
   - ขาย models บน Creator Marketplace
   - ขาย plugins
   - ขาย scripts/systems

4. SPONSORSHIPS / PARTNERSHIPS
   - Brand deals สำหรับเกมที่ popular
   - Roblox Events participation
   - Platform promotions

5. EDUCATION
   - สร้าง course สอน Roblox (เหมือน course นี้!)
   - Coaching/mentoring
   - Workshops

Revenue Projection ตัวอย่าง:
   เกมใหม่ที่มี 1,000 DAU:
   - If ARPU = $0.10/day
   - Monthly revenue = 1000 × $0.10 × 30 = $3,000/month
   - Yearly = $36,000
   
   เกมใหญ่ที่มี 50,000 DAU:
   - Monthly revenue = $150,000
   - Yearly = $1,800,000
```

### 6.2 Interview Questions และ Answers

```
คำถามยอดนิยมในการ Interview:

Q: "Tell me about your most complex system"
A ที่ดี: 
"ผมสร้าง combat system สำหรับ MMO RPG ที่มี lag compensation,
server-side hit detection, และ 15 abilities ต่างๆ
ความท้าทายที่ใหญ่สุดคือ latency compensation —
ผมแก้ด้วยการเก็บ position history 1 วินาทีย้อนหลัง
และ interpolate ตำแหน่งของ player เมื่อ server ตรวจสอบ hit
ผลลัพธ์คือ hit registration ที่ accurate แม้ผู้เล่นมี 200ms ping"

Q: "How do you handle memory leaks?"
A ที่ดี:
"ผมใช้หลายเทคนิค:
1. Disconnect connections เมื่อ instance ถูก destroy
2. ใช้ Maid pattern สำหรับ cleanup
3. ตรวจสอบ memory ด้วย Debug library
4. Profile ด้วย Roblox Microprofiler เป็นประจำ
ใน ProfileService project ของผม ผม detect leak จาก
connections ที่ไม่ได้ disconnect ด้วย custom Maid class"

Q: "Explain your approach to DataStore"
A ที่ดี:
"ผมใช้ ProfileService สำหรับ session locking เพื่อป้องกัน
data corruption เมื่อหลาย server เข้าถึง data พร้อมกัน
แต่ละ save มี retry logic พร้อม exponential backoff
และผมเก็บ backup ทุก 5 นาทีเพื่อ disaster recovery"

Q: "How do you optimize Roblox games?"
A ที่ดี:
"ผม approach optimization เป็นขั้นตอน:
1. Profile ก่อน optimize (ใช้ Microprofiler, Script Performance)
2. Client-side optimization: LOD system, frustum culling
3. Server-side: ลด heartbeat callbacks, batch operations
4. Network: event batching, data compression
5. Test บน low-end device จริงๆ เสมอ"

Q: "How do you prevent exploits?"
A ที่ดี:
"หลักการหลักคือ 'Never trust the client'
ทุก action ที่ส่งมาจาก client ต้องผ่าน server validation
ผมมี server-side validator ที่ตรวจสอบ:
- Action ทำได้จริงไหม (range, cooldown, resources)
- Rate limiting ป้องกัน spam
- Sanity checks บน values (damage ไม่เกิน max)
และ automatic flagging เมื่อพบ anomaly"
```
